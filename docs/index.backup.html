How a line gets spoken

Game hook → Localhost → Gemini once → ElevenLabs stream
01 / STEAM SCAN libraryfolders.vdf

Local Engine Detection

Parses Steam's local appmanifest_*.acf files and inspects game directories for engine signatures rather than relying on store tags. Ticking a game copies dubgame.rpy into game/; unticking removes it.

02 / ENGINE CALLBACK config.all_character_callbacks

Exact Text Without Screen Reading

Hooks directly into the game's dialogue callback on a background thread. Every spoken line dispatches { speaker, text } to 127.0.0.1:8000/line with Text tags like {w} stripped cleanly.

03 / CHARACTER PROFILING voices.json

One-Time Gemini Casting

New speakers are profiled once against a 12-voice catalog using schema-enforced JSON output (gender, age range, personality, stability, style, speed). Subsequent lines bypass Gemini and route straight to TTS.

04 / ELECTRON OVERLAY safeStorage + IPC

Always-On-Top Voice Controls

Press Shift + F2 over windowed or borderless games to override voice IDs, tweak sliders, or re-roll casting. Player API keys stay encrypted in the main process via Electron safeStorage.
